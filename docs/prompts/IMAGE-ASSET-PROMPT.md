# 이미지 자산 생성 프롬프트

저장소에 커밋되는 이미지 파일을 만들 때 생성 도구에 넣은 프롬프트를 보존한다. 화면 시안을 받는 프롬프트는 CLAUDE-DESIGN-PROMPT.md가 맡는다.

지난 프롬프트는 고치지 않고 새 시도를 아래에 쌓는다. 디자인 방향이 바뀌면 DESIGN.md를 고치고 여기에는 새 프롬프트를 추가한다. 지난 항목을 방향에 맞춰 고치면 어떤 입력이 어떤 파일을 냈는지 대조할 수 없게 된다.

## 자산 목록

| 자산                 | 파일                                          | 규격                 | 쓰는 곳                        |
| -------------------- | --------------------------------------------- | -------------------- | ------------------------------ |
| 심볼 마크            | `public/favicons/logo-mark.svg`               | 벡터, 정사각         | 파비콘과 OG, 뱃지의 원본       |
| 파비콘               | `public/favicons/favicon.ico`                 | 16, 32, 48 다중      | 브라우저 탭                    |
| 파비콘 PNG           | `public/favicons/favicon-16x16.png`, `-32x32` | 16x16, 32x32         | 브라우저 탭 대체               |
| 애플 터치 아이콘     | `public/favicons/apple-touch-icon.png`        | 180x180, 배경 불투명 | iOS 홈 화면                    |
| 안드로이드 아이콘    | `public/favicons/android-chrome-192x192.png`  | 192x192              | 안드로이드 홈 화면, manifest   |
| 안드로이드 큰 아이콘 | `public/favicons/android-chrome-512x512.png`  | 512x512              | manifest, 설치 화면            |
| 기본 OG 이미지       | `public/images/default-og-image.png`          | 1200x630             | 목록 페이지와 썸네일 없는 공유 |
| OG 배경              | `/og` 라우트가 그림                           | 1200x630             | 글 공유 카드 배경              |
| 뱃지 대체 배경       | `/badge` 라우트가 그림                        | 480x270              | 썸네일 없는 글의 README 카드   |
| 썸네일 대체          | `public/images/post-placeholder.png`          | 1600x900             | 썸네일 없는 글의 목록 카드     |

`logo-mark.svg`와 `android-chrome-512x512.png`, `post-placeholder.png` 셋은 아직 없다. v1.3.0에서 만든다. 심볼 마크가 파비콘과 OG, 뱃지의 원본이므로 그것부터 만든다. 512 아이콘은 manifest에 등록해야 설치 화면에서 흐릿하게 나오지 않는다.

## 공통 조건

어떤 자산을 만들든 아래를 지킨다.

- 브랜드 색은 `#4f46e5`다. 어두운 면은 `#0f172a`에서 `#1e1b4b` 사이를 쓴다
- 글자를 넣어야 하면 Pretendard로 렌더한다. 한글이 시스템 폰트로 대체되면 다시 만든다
- 사람 얼굴과 실사 사진, 스톡 일러스트를 쓰지 않는다
- 그라디언트는 두세 색 사이의 완만한 흐름까지만 쓴다. 무지개와 강한 색 대비를 만들지 않는다
- 라이트와 다크 양쪽에서 확인한다. 한쪽에서만 보이는 색은 쓰지 않는다

## 검수 기준

받은 결과를 커밋하기 전에 확인한다.

- 파비콘은 16x16으로 줄여서 형태가 남는지 본다. 획이 겹치거나 뭉개지면 다시 만든다
- 애플 터치 아이콘은 투명 배경이면 안 된다. iOS가 검게 채운다
- OG 이미지는 실제 공유 미리보기에서 확인한다. 글자가 올라갈 자리에 배경 무늬가 겹치면 읽히지 않는다
- PNG는 압축한다. OG 이미지는 300KB 아래를 목표로 한다
- 생성 도구가 넣은 워터마크와 서명이 없는지 확대해 본다

## 2026-08-20 v1.3.0 심볼 마크

헤더 로고는 텍스트 `<chan9yu />`를 그대로 쓴다. 다만 파비콘과 OG, 뱃지처럼 글자를 넣을 수 없는 자리에는 심볼이 필요하다. 그 자리에 쓸 마크를 만든다.

```
개발 블로그의 심볼 마크를 만들어줘. 512x512 정사각형 벡터, 배경 투명.

컨셉: 코드의 꺾쇠 괄호에서 출발한 형태.
왼쪽 꺾쇠와 오른쪽 꺾쇠가 마주 보되 완전히 닫히지 않고 가운데에 틈이 있는 모양.
획은 굵고 끝은 살짝 둥글게. 기하학적이고 좌우 대칭.

색은 단색 #4f46e5 하나만. 그라디언트와 그림자, 테두리는 넣지 마.
글자와 사람, 아이콘 클리셰(전구, 로켓, 톱니바퀴)는 넣지 마.

16x16으로 줄여도 두 꺾쇠가 구분되어야 해.
획 사이 간격을 획 두께보다 넓게 잡아줘.
```

이 마크를 흰색 단색 버전으로도 받는다. 어두운 배경에 얹는 자리에 쓴다.

## 2026-08-20 v1.3.0 파비콘

심볼 마크를 배경 위에 올려 만든다. 마크를 그대로 축소하면 여백이 없어 탭에서 답답해 보인다.

```
앞서 만든 심볼 마크로 파비콘을 만들어줘.

512x512 정사각형. 배경은 #4f46e5 단색으로 꽉 채우고
그 위에 흰색(#ffffff) 심볼 마크를 가운데 배치.
마크 크기는 전체의 60퍼센트, 사방 여백 20퍼센트씩.

모서리는 둥글리지 마. 브라우저와 OS가 알아서 자른다.
그림자와 광택, 테두리를 넣지 마.
```

받을 파일은 512와 192, 180, 32, 16 크기의 PNG와 `favicon.ico`다. 180x180 애플 터치 아이콘은 배경이 반드시 불투명해야 한다.

## 2026-08-20 v1.3.0 OG 배경

글자는 코드가 그려 넣으므로 배경만 만든다.

```
블로그 공유 카드의 배경 이미지를 만들어줘. 1200x630 가로.

왼쪽 위에서 오른쪽 아래로 흐르는 대각 그라디언트.
색은 #0f172a에서 시작해 #1e1b4b를 지나 #4f46e5로 끝나.
표면에 아주 옅은 노이즈 질감을 넣어 단조로운 면을 깨줘.
눈에 띄면 안 되고 가까이 봐야 보이는 정도로.

가운데와 왼쪽 아래는 글자가 올라갈 자리라 비워둬.
로고와 문자, 아이콘, 도형은 넣지 마. 배경만.
오른쪽 위 구석에만 옅은 빛 번짐을 둬도 좋아.
```

이 배경 위에 코드가 얹는 것은 위쪽 작은 글씨(태그 또는 도메인), 가운데 제목, 아래쪽 도메인과 블로그 이름이다.

## 2026-08-20 v1.3.0 기본 OG 이미지

목록 페이지가 공유될 때 쓰는 정적 이미지다. 위 배경에 심볼과 블로그 이름을 얹은 형태다.

```
위에서 만든 OG 배경을 그대로 쓰고 그 위에 다음을 배치해줘. 1200x630.

가운데에 흰색 심볼 마크, 크기는 높이의 20퍼센트.
그 아래 24px 간격으로 "chan9yu" 를 흰색 굵은 글씨 64px로.
그 아래 16px 간격으로 "프론트엔드 개발 블로그" 를 #a5b4fc 색 32px로.
전체를 세로 가운데 정렬.

글자는 Pretendard로 렌더해줘. 한글이 깨지거나 다른 폰트로 나오면 안 돼.
```

## 2026-08-20 v1.3.0 뱃지 대체 배경

썸네일이 없는 글의 README 카드에 쓴다. 480x270 영역이다.

```
480x270 가로 이미지를 두 벌 만들어줘. 블로그 글 카드의 썸네일 자리 대체 배경이야.

다크 버전: #0a0a0a 바탕에 #4f46e5가 아주 옅게 번지는 형태.
라이트 버전: #ffffff 바탕에 #eef2ff가 아주 옅게 번지는 형태.

두 버전 모두 위에서 아래로 갈수록 옅어지고 가운데는 비워둬.
가운데에 심볼 마크를 넣되 배경과 거의 구분되지 않을 만큼 옅게.
다크는 흰색 마크를 불투명도 8퍼센트로, 라이트는 #4f46e5 마크를 불투명도 8퍼센트로.

다른 글자와 아이콘은 넣지 마.
```

카드 아래쪽에 제목과 날짜가 얹히므로 아래 3분의 1은 단색에 가까워야 한다.

## 2026-08-20 v1.3.0 썸네일 대체

썸네일이 없는 글이 목록 격자에 나올 때 쓴다. 지금은 회색 면으로 비워둔다.

```
1600x900 가로 이미지. 블로그 글 목록에서 썸네일이 없는 글의 자리에 들어가.

아주 낮은 대비의 배경 하나만 만들어줘.
라이트 버전은 #f8fafc에서 #eef2ff로 흐르는 완만한 대각 그라디언트.
다크 버전은 #18181b에서 #1e1b4b로.

가운데에 심볼 마크를 불투명도 10퍼센트로 크게 배치.
글자는 넣지 마.

목록에 여러 장이 나란히 놓여도 시끄럽지 않아야 하니
어떤 요소도 눈에 먼저 들어오면 안 돼.
```
