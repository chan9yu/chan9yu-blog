# 클로드 디자인 프롬프트

디자인 생성 도구에 넣은 프롬프트를 결과물 설명과 함께 보존한다. 지난 프롬프트는 고치지 않고 새 시도를 아래에 쌓는다.

디자인 방향이 바뀌면 DESIGN.md를 고치고 여기에는 새 프롬프트를 추가한다. 이 문서의 지난 항목을 방향에 맞춰 고치면 어떤 입력이 어떤 결과를 냈는지 대조할 수 없게 된다.

## 2026-08-20 v1.3.0 화면 시안

목적은 v1.2.0 화면을 기준선으로 두고 가독성과 상호작용을 개선한 시안을 받는 것이다. 아래 프롬프트를 그대로 넣는다.

```
한국어 기술 블로그의 화면 시안을 만들어줘. 1인 저자가 프론트엔드 실무 글을 쓰는 블로그이고
독자는 검색으로 도착한 한국어권 개발자야. 이미 운영 중인 사이트의 개선 시안이라
디자인 시스템은 아래를 그대로 지키고 배치와 상호작용만 개선해줘.

[인상]
차분하다. 정확하다. 읽기 편하다.
긴 글을 끝까지 읽게 하는 것이 목적이라 화면이 먼저 눈에 띄면 안 된다.
장식은 콘텐츠가 요구할 때만 넣는다.

[색]
라이트: 바탕 #ffffff, 보조 바탕 #f8fafc, 본문 글자 #0f172a, 보조 글자 #475569,
        테두리 #e2e8f0, 액센트 #4f46e5
다크: 바탕 #09090b, 보조 바탕 #18181b, 본문 글자 #f8fafc, 보조 글자 #cbd5e1,
      테두리 #27272a, 액센트 #818cf8
액센트는 링크와 활성 상태에만 쓴다. 넓은 면을 액센트로 칠하지 않는다.

[타이포그래피]
본문 폰트는 Pretendard 하나. 코드는 시스템 고정폭.
본문 16px, 줄 간격 1.75, 본문 폭 44rem 상한.
제목 위 여백을 아래 여백의 1.5배로 둔다.
한글 본문이라 어절 단위로 줄이 바뀐다. 짧은 줄에서 어절이 끊기지 않게 폭을 확보해줘.

[모서리와 그림자]
카드 12px, 코드 블록과 버튼 8px, 태그 칩은 알약.
그림자는 라이트에서 아주 옅게, 다크에서는 진하게.

[만들 화면]
1. 홈: 인사말, 최근 글 6편 카드, 오른쪽 사이드바(인기 글 5, 인기 시리즈 3, 인기 태그 10)
2. 포스트 목록: 왼쪽 태그 목록, 오른쪽 카드 격자, 위에 격자와 목록 뷰 토글
3. 포스트 상세: 읽기 진행률 막대, 제목과 메타(날짜, 조회수, 태그, 공유),
   본문, 오른쪽 고정 목차, 이전과 다음 글, 관련 글, 댓글
4. 태그 허브: 태그 카드 격자
5. 시리즈 허브: 시리즈 카드에 앞 3편 미리보기
6. About: 프로필과 소개 본문

[각 화면마다 필요한 폭]
모바일 세로 375px, 태블릿 세로 768px, 태블릿 가로 1024px, PC 1440px 네 가지.
모바일 가로(높이 400px 아래)에서 고정 헤더가 화면을 잡아먹지 않는 배치도 함께.

[라이트와 다크]
두 테마 모두 만들어줘. 다크는 라이트의 색만 바꾼 것이 아니라
그림자와 테두리 대비를 다시 잡은 것이어야 한다.

[하지 말 것]
- 큰 히어로 이미지나 그라디언트 배경
- 스크롤을 가로채는 연출, 패럴랙스
- 옅은 회색 글자로 만드는 저대비 미니멀리즘
- 유리 질감과 과한 블러
- 아이콘 남발. 아이콘은 뜻이 분명한 자리에만

[접근성]
본문 대비 4.5대 1 이상, 큰 글자와 테두리는 3대 1 이상.
클릭 대상은 최소 44x44px.
포커스 표시를 각 상호작용 요소에 그려줘.
```

받은 결과와 채택 여부는 확인한 뒤 여기에 덧붙인다.
